# Security policy

## Supported code

Security fixes target the current source on `main` and the latest published package versions. Older versions may require an upgrade.

## Report a vulnerability

Do not open a public issue for a vulnerability that could expose users, credentials, private material, or rights evidence.

Email `achorde.cifras@gmail.com` with:

- the affected package and version;
- a clear reproduction or proof of concept;
- the likely impact;
- any known workaround.

Do not include real secrets, private contracts, personal data, or copyrighted chart bodies. No response-time or reward program is promised.
