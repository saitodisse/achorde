# Code of Conduct

Achorde welcomes people who collaborate with care, patience, and respect.

## Expected behavior

- Discuss ideas and code without attacking people.
- Give specific, useful feedback and accept corrections in good faith.
- Respect different backgrounds, identities, experiences, and skill levels.
- Keep project spaces free of harassment, discrimination, threats, and unwanted sexual attention.

## Scope and enforcement

This code applies in repository discussions, reviews, issues, and other spaces where someone represents the project. Maintainers may edit or remove harmful content and restrict participation when needed to protect the community.

Report conduct concerns privately to `achorde.cifras@gmail.com`. Include only the context needed to understand the incident. Reports will be handled as privately as practical; no response-time promise is made.
