# achorde

Monorepo for the shared music ecosystem.

## Contents

- `packages/musical-domain` - shared musical domain contracts
- `packages/svguitar-react` - React/SVG chord diagram library
- `packages/tab-renderer` - chord sheet parser and renderer

## Root Commands

- `pnpm install`
- `pnpm build`
- `pnpm test`
- `pnpm lint`
- `pnpm typecheck`

## Install (consumers)

Packages are not on npm yet. Install from the monorepo (see each package `README.md`) or publish from `packages/*` when ready.

Repository: [github.com/achorde/achorde](https://github.com/achorde/achorde)
