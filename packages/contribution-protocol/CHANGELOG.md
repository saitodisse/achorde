# Changelog

## 0.3.0

### Added

- Version 3 manifests with versioned terms and fixed `CC-BY-NC-SA-4.0` content licensing.
- Explicit rejection of rights attestations, `evidenceId`, the `rights-evidence` role, and evidence paths in new bundles.

## 0.2.0 - 2026-08-11

### Added

- Version 2 manifests for atomic artist/work/chart contributions.
- Editorial path allowlist, base/content hash rules, rights attestations, and bundle limits.
- Canonical entry ordering and contribution/ZIP idempotency keys.

## 0.1.1 - 2026-08-08

### Added

- First public release of the portable, forge-neutral contribution protocol.
